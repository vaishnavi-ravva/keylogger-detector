## 📌 About The Project

Cyber Keylogger Detector is a beginner-friendly cybersecurity project built using Python.  
The program scans running system processes and identifies suspicious applications using keyword-based detection techniques.

It demonstrates:
- 🛡️ Malware Detection Basics
- ⚙️ Process Monitoring
- 🧠 Cybersecurity Concepts
- 🐍 Python Programming

---

## 🚀 Features

✅ Detects suspicious processes  
✅ Lightweight and fast  
✅ Real-time scanning  
✅ Beginner-friendly project  
✅ Simple and clean terminal output
